## What this is

`main.py` writes a single short plan — at most 280 characters — to
`entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR`. The plan
describes how an AI agent, working alone, turns $100 into the most
money it can within 30 days: selling freshly verified lead lists of
brand-new businesses to marketing agencies. The edge is freshness —
a firm that opened this month needs customers now, and a list that is
code-verified this week beats the stale lists everyone else resells.
The plan text is exactly 276 characters long.

The plan (276 characters):

> Day 1: scrape registries for firms opened this month, code-verify emails, send 30 agencies a free 20-lead sample. Sell niche lists at $99, refreshed weekly; $100 covers domain, email tool, API credits. Edge: new firms need customers now; fresh verified leads beat stale lists.

Run: `MAKEFUN_OUTPUT_DIR=<dir> python3 main.py`
